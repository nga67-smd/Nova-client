# Nova HUD (Fabric mod)

In-game overlay for Nova Launcher. Press **Right Shift** (rebindable) to open the menu:

- Sidebar (scoreboard): hide, resize, move up/down
- Armor HUD on the left (or right) with durability
- View model: move, resize and rotate the held item/hand
- FPS and coordinates lines

Client-side only; settings are saved to `config/nova-hud.json`. Needs Fabric Loader and Fabric API.

## Build
Actions tab -> **Build Nova HUD mod** -> Run workflow, then download `nova-hud-<version>` from the run.
Put the `.jar` in an instance's `mods` folder. Supported: Minecraft 1.21.1 for now.
